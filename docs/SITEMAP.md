# Sitemap

Source of truth: `server/config/site-routes.js`. The same list drives the dev server, `vercel.json` rewrites, the pre-rendered language versions, `sitemap.xml` (public pages only) and the `/sitemap` page.

Access: **public** — anyone · **guest** — signed-out visitors (signed-in users are sent to the dashboard) · **user** — signed-in customers · **staff** — signed-in staff with the page's permission.

## Public pages

Pre-rendered in four languages: `/path` (English), `/ru/path`, `/ar/path` (right-to-left), `/ka/path` (Georgian), with `canonical` and `hreflang` links. Listed in `sitemap.xml`.

| Path | Page | Purpose |
| --- | --- | --- |
| `/` | Home | what the platform is, the ledger strip explained, how money moves, fees, risks |
| `/how-it-works` | How it works | deposit → 7-day hold → invest → realised results → withdraw, step by step |
| `/products` | Products | active products with full terms and the scenario calculator |
| `/risk-disclosure` | Risk disclosure | risks of crypto assets and of each product type |
| `/faq` | FAQ | common questions, grouped |
| `/contact` | Contact | support address and how to open a ticket |
| `/sitemap` | Sitemap | this list, for people |
| `/legal/terms` | Terms of Service | template — legal review required |
| `/legal/privacy` | Privacy Policy | template — legal review required |
| `/legal/cookies` | Cookie Policy | only strictly necessary cookies are used |

## Account

| Path | Access | Purpose |
| --- | --- | --- |
| `/login` | guest | email + password, then the two-factor code when enabled |
| `/register` | guest | registration with country, legal acceptance, optional referral code |
| `/forgot-password` | guest | request a reset link |
| `/reset-password` | public | set a new password from the emailed link (`?token_hash=…&type=recovery`) |
| `/verify-email` | public | confirm the email from the link (`?token_hash=…&type=signup`) |

## Other files
